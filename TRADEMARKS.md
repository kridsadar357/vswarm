# The vswarm name and logo

The code is Apache-2.0: you may use it, change it, fork it and ship your own version. The license does not cover
the name **vswarm** or the worm logo (Apache-2.0, section 6). This page says how to use them.

**Fine without asking**

- Saying your project uses, works with, or is based on vswarm.
- Writing about vswarm, teaching it, showing its output, with the logo, unchanged.
- An unmodified copy built from an official release, called vswarm.

**Please use another name and logo**

- A fork or modified version you distribute. Name it something else, and say it is based on vswarm.
- A product or service that could be mistaken for the official project, or for one the maintainer endorses.

**Why this matters for a security tool**

People install vswarm to guard their path to production, and they trust what it tells them. A copy with the same
name and changed code, maybe with a check quietly removed, is exactly the kind of thing vswarm warns about. That is
why official releases are signed (see [SECURITY.md](SECURITY.md#signed-releases)), and why the name stays with
the official project.
